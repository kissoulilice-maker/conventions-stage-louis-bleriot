# Utilisateurs et rôles

## Profils concernés

DocuBlériot doit prendre en compte les personnes qui interviennent dans la préparation et la validation d'une convention de stage.

| Profil | Rôle dans le parcours |
|---|---|
| Élève | Bénéficie de la convention et suit son avancement |
| Professeur référent | Vérifie et signe la convention |
| Tuteur de stage | Représente l'encadrement dans l'entreprise |
| Directeur | Intervient dans le circuit de validation prévu |
| Entreprise | Valide la convention selon l'organisation retenue |
| Responsable légal | Signe lorsque l'élève est mineur |
| Étudiant majeur | Signe lui-même à la place du responsable légal, selon le cas |

## Les cinq rôles de signature prévus

Le modèle DocuSeal « Convention PFMP – DocuBlériot » a été conçu autour de cinq rôles :

1. Professeur référent.
2. Tuteur de stage.
3. Directeur.
4. Entreprise.
5. Responsable légal ou étudiant majeur.

La répartition exacte entre « tuteur » et « entreprise », ainsi que l'ordre de signature, doivent être confirmés avec l'établissement pour éviter les doublons ou les validations incorrectes.

## Gestion des droits à prévoir

- Un utilisateur ne doit accéder qu'aux conventions nécessaires à son rôle.
- Les informations personnelles doivent être visibles uniquement par les personnes autorisées.
- Les actions importantes doivent être traçables.
- Les liens de signature ne doivent pas être considérés comme un remplacement automatique d'une vérification d'identité renforcée.

## État

Les rôles ont été définis pour le modèle de signature. La gestion complète des comptes, des autorisations et des accès dans l'application DocuBlériot reste à développer et à tester.
