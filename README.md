# Gestion dématérialisée des conventions de stage

Ce dépôt est un fork du dépôt de travail de K.B. Étudiant en CS Cybersécurité au Lycée Louis Blériot de Trappes.
Pour plus d'informations sur l'auteur, consulter directement le dépôt original.

Ce projet a été réalisé lors d'un stage dans la société ScientificWare qui l'a missionné pour cette étude de faisabilité.

L'objet de ce dépôt est de dupliquer le contenu du dépôt d'origine pour :
- suivre et évaluer le travail réalisé,
- apporter des corrections ou des suggestions,
- faciliter l'intégration de nouveaux collaborateurs.

### Dépôt GitHub du projet

Le code source et la documentation du projet sont disponibles sur le dépôt GitHub :

**GitHub :** [conventions-stage-louis-bleriot](../../wiki)

## Présentation du projet

Ce projet a pour objectif de mettre en place une solution permettant de gérer les conventions de stage de manière dématérialisée.

L'application doit permettre de créer, gérer, suivre, valider et faire signer les conventions de stage.

---

### Objectifs détaillés du projet

- Dématérialiser les conventions de stage.
- Faciliter la création des conventions.
- Permettre le suivi de l'état des conventions.
- Mettre en place un système de validation.
- Gérer les différentes signatures.
- Centraliser les documents.
- Faciliter le travail des élèves, des entreprises et du personnel du lycée.
- Améliorer le suivi des conventions.
- Étudier et utiliser des solutions Open Source adaptées au projet.
